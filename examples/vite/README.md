# Vite example

A React + TypeScript app built with Vite that uses every part of `react-use-translation`:

- `useTranslation` for plain strings
- `Translate` with a placeholder
- a pluralized counter via a template expression
- array paths like `weekdays.days[0]`
- `withTranslation` on a class component
- languages loaded on demand with `useUpdateTranslation`

```bash
npm install
npm run dev
```
